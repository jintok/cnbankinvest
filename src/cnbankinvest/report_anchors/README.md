# 每银行 PDF 提取锚点覆盖（可选）

默认正则（report_extractor.py `DEFAULT_PATTERNS`）已覆盖工行/招行实测版式；
某行报告标签写法特殊、默认提取不准时，在此放 `{a_code}.json` 覆盖：

```json
{
  "page_range": [1, 60],
  "patterns": {
    "净息差": "净利息收益率(?:[（(]\\d+[)）])?[^\\d\\-+％%]{0,20}(\\d[\\d,]*\\.?\\d*)"
  }
}
```

- `patterns`：键为指标名（与默认同名即覆盖），值为正则字符串，**第一个捕获组 = 数值**。
- `page_range`：扫描页范围（1 起始），指标集中在摘要/主要会计数据/管理层讨论前 60 页。
- 提取结果众数 + 首现值兜底，取值口径为「本集团」法定披露表。
