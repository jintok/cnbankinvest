## 研究范围

- **覆盖标的池**：12 家上市银行（国有大行 6：工农中建交邮储；股份行 3：招商/兴业/平安；城商行 3：宁波/江苏/成都），其中 7 家为 A+H 双重上市。
- **基准指数（6）**：沪深300（000300，基准）、中证银行（399986）、申万银行（801780）、中证红利（000922，红利风格）、中证银行AH价格优选（931039，A/H 因子）、中证智选高股息策略（932305，第二代红利策略）。
- **产出**：每周板块周报 + 单只个股报告，均为**纯自动「指标 + 图表」仪表盘，无人工撰写段落**。

## 周报结构（逐节定义）

- **一、一周速览**：指数表（6 指数：收盘/周涨跌/YTD）+ 估值水位行（核心池 PB 中位数及分位、股息率中位数、股息率−10Y 利差）+ 利率汇率行（10Y/Shibor/LPR/南向资金/AH 溢价均值）+ 指数相对走势图。
- **二、本周变化**：A 股涨跌前 3 后 3、南向资金周净流入、10Y 周变动、AH 溢价环比 + 周涨跌条形图。
- **三、跨指数比较**：
  - **相关性矩阵**：6 指数两两近 1 年日收益 Pearson 相关系数矩阵（hist 日线缓存计算）；
  - **股息率对比矩阵**：12 家银行股息率 TTM（自算，含近 5 年分位、对 10Y 利差）vs 可得指数股息率（中证官网股息率2 口径，仅当前值 + 对 10Y 利差，无历史分位）。
- **四、估值水位**：12 家 PB 及近 5 年分位、股息率及分位、52 周位置、PB-ROE 对照汇总表 + 分布图。
- **五、A/H 因子**：931039 相对 399986 周超额及解读、7 家 A+H 溢价率均值/中位数及环比、南向资金 + AH 溢价图。
- **六、基本面摘要**：最新报告期覆盖度、营收/净利 YoY 中位数、ROE（累计）区间、净息差/不良率/拨备覆盖率/资本充足率/分红率汇总、存款/贷款 YoY 中位数、逾期率汇总。
- **七、宏观与利率**：10Y 国债、Shibor 1W、LPR 1Y/5Y（最近报价及近一次变动）、商业银行普通债 AAA 3Y−国债 3Y 信用利差、社融/信贷（可得时）。
- **附1 个股行情估值明细**：在周收盘/H 收盘/AH 溢价/PB/PE-TTM/股息率/利差基础上，加 PB 分位、股息率分位、52 周位置列。
- **附2 个股基本面明细**：营收/净利 YoY、ROE（累计）、EPS/BVPS、净息差、净利差、不良率、逾期率、拨备覆盖率、核心一级/资本充足率、分红率、存款/贷款余额及 YoY。

## 个股报告结构（逐节定义）

- **一、关键指标仪表盘**：估值（PB/PE-TTM/股息率/利差/各自分位）+ 52 周位置 + PB-ROE 定位 + 规模与资产质量关键行，一览表。
- **二、近期行情与市场表现**：A/H 周涨跌、相对沪深300/中证银行强弱、相对走势图。
- **三、估值分析（全自动）**：PB/股息率历史分位与近 5 年区间、52 周高低与回撤、PB-ROE 相对板块中位偏离。
- **四、基本面分析**：报告期趋势表（营收/净利/ROE/EPS/BVPS）+ 专项指标（净息差/不良/逾期/拨备/资本/分红率）+ 规模增速。
- **五、风险提示**：通用模板（息差/资产质量/地产城投/政策），自动保留。

## 指标口径

| 指标 | 口径 |
|---|---|
| 周涨跌 | 最新收盘（≤数据截止日的最后交易日）对比 7 个自然日前收盘，% |
| 年初至今 | 对比上一年最后交易日收盘，% |
| 股息率 TTM | 近 365 天除权除息现金分红（元/10股÷10）÷ 现价，%（自算口径） |
| 利差 | 核心池 12 家股息率中位数 − 10Y 国债收益率，pct |
| AH 溢价 | (H股收盘价×CNY/HKD − A股收盘价) ÷ A股收盘价，负值=H股折价 |
| 南向资金 | 港股通近 5 个交易日「当日成交净买额」合计，亿港元 |
| PB / PE-TTM | 东财 datacenter-web 日频估值，取 ≤截止日最新一日 |
| PB 分位 | 当前 PB 在近 5 年（约 1250 交易日）日频 PB 序列中的百分位，%（估值缓存 valuation_hist） |
| 股息率分位 | 自算历史股息率序列（每日：近 365 天分红 ÷ 当日收盘）近 5 年百分位，% |
| 52 周位置 | (现价 − 52 周最低) ÷ (52 周最高 − 52 周最低)，%；另列距 52 周高点回撤 |
| PB-ROE | PB 与 ROE（最新期累计 ROE × 4/季度序数 年化，%）对照；偏离度 = 个股 PB/ROE ÷ 板块中位 PB/ROE − 1 |
| 相关性矩阵 | 指数日收益（hist 缓存收盘价环比）近 1 年（约 250 交易日）Pearson 相关系数 |
| 指数股息率 | 中证官网估值接口股息率2（计算用股本加权口径），取 ≤截止日最新；仅当前值，无历史分位 |
| 信用利差 | 中债商业银行普通债收益率曲线(AAA) 3年 − 中债国债收益率曲线 3年，pct |
| LPR | macro_china_lpr 最近一期 1Y/5Y 报价及相对上一期变动，%（月度，每月 20 日） |
| 营收/净利/ROE | 同花顺按报告期（均为累计值口径；ROE 年化 = 累计 × 4/季度序数） |
| EPS / BVPS | 东财 F10 主要指标 EPSJB / BPS，按报告期 |
| 规模增速 | 东财 F10 主要指标 TOTALDEPOSITS / GROSSLOANS，对上年同报告期自算 YoY，% |
| 逾期率 | 东财 F10 主要指标 OVERDUE_LOANS ÷ GROSSLOANS，% |
| 净息差/不良率/拨备/资本/分红率 | 东财 F10 主要指标 + 分红送配自动拉取（fin_indicators_puller，口径同 v20260927） |

## 数据源与可用性

- **主源**：新浪（A/H 个股日线、汇率牌价）、中证指数官网（指数日线 + 指数估值/股息率）、申万宏源（801780）、中国债券信息网（10Y/3Y 国债 + 商业银行普通债 AAA 曲线）、同花顺（财务摘要）、东方财富 datacenter-web（个股估值/F10 主要指标/分红送配，带重试）、macro_china_lpr（LPR）。
- **受限**：东财行情接口（push2/push2his）在部分网络环境（HTTP 代理）下不可达，不使用。
- **已移除**：新闻快讯与公告（东财/财联社）不再进入报告与流水线。

## 评估与投资框架

### 估值双锚

1. **股息率−10Y 利差（主锚）**：利差 > +3.0pct 为低估区（超配信号）；+2.0~+3.0pct 为合理偏低（标配偏多）；+1.0~+2.0pct 为合理（标配）；< +1.0pct 为高估区（低配信号）。
2. **PB 近 5 年分位（辅锚）**：板块 PB 中位数分位 < 20% 低估；20%–50% 合理；50%–80% 偏高；> 80% 高估。
3. 两锚冲突时以利差为准——银行股的类债属性使股息贴现口径比 PB 更直接。

### 跨指数性价比

- 银行股息率中位数 vs 中证红利/智选高股息股息率：银行相对红利指数的股息率差 > 0 且 PB 分位更低时，银行板块在红利风格内占优；反之减配银行、偏向宽基红利。
- 相关性矩阵用于组合层面：中证银行与其他指数相关性显著下降时，银行的分散化价值上升。

### A/H 轮动

- AH 溢价均值 < −15%（H 折价深）且南向资金持续净流入 → 优先 H 侧；溢价 > −5%（折价收敛）→ 回到 A 侧或均衡。
- 931039 相对 399986 周超额用于验证轮动方向是否被市场价格确认。

### 资产质量红线（个股）

- 不良率 > 2.0%、拨备覆盖率 < 150%、或逾期率环比上行 > 0.3pct——触发任一即降级（移出超配候选），等待下期数据确认修复。

### 个股相对估值

- PB-ROE 框架：偏离度（PB/ROE 相对板块中位）< −20% 且不触资产质量红线 → 相对低估候选；> +20% → 相对高估，谨慎加仓。

### 仓位纪律（板块）

| 利差（主锚） | PB 分位（辅锚） | 结论 |
|---|---|---|
| > +3.0pct | 任意 | 超配 |
| +2.0~+3.0pct | < 50% | 标配偏多 |
| +1.0~+2.0pct | 任意 | 标配 |
| < +1.0pct | > 50% | 低配 |

## 已知限制

- 指数股息率仅有近 1 个月当前值（中证官网估值接口限 20 行），**指数股息率无历史分位**；银行股息率分位为自算口径。
- 行业监管指标（金监总局季度通报口径）无自动数据源，v2 起不再纳入报告。
- akshare 无商业银行不良生成率/关注类贷款占比自动源；资产质量前瞻仅覆盖逾期率。
- 南向资金周合计为近 5 个交易日口径（非自然周）。
- 10Y 国债取值需过滤「中债国债收益率曲线」（同接口另返回中短期票据/商业银行普通债曲线）。
- 801780（申万银行）无估值/股息率数据，跨指数矩阵中该指数仅参与相关性矩阵。
